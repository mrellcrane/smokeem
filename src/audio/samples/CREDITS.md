# Sound credits

Every recording here is CC0 (public domain), from OpenGameArt. The clips were cut, layered
and mastered with `tools/build_sounds.py`; the sub-bass thumps and the rocket roar in
`launch.wav` are synthesized there too.

| File | Source |
| --- | --- |
| `shot-1` to `shot-4` | AK-47 single shots, near (C_28P), [The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library) |
| `shotgun-1`, `shotgun-2` | Benelli Nova 12 gauge, near (O_21P), same library |
| `pump`, `shell-1`, `shell-2` | Rack, Shell in Chamber, [Shotgun Reload Sound Effects](https://opengameart.org/content/shotgun-reload-sound-effects) |
| `reload`, `swap` | assaultriflereload1, gunreload1, [Gun reload sounds](https://opengameart.org/content/gun-reload-sounds) |
| `boom-1`, `boom-2` | cannon_02, bang_03, bang_09, fw_06, [25 CC0 bang / firework SFX](https://opengameart.org/content/25-cc0-bang-firework-sfx) |
| `launch` | shot_01 from the same bang pack, plus a synthesized rocket roar |
| `pistol-1` to `pistol-3` | Walther PPQ 9mm, near (X_39P), The Free Firearm Sound Library |
| `smg-1` to `smg-3` | Carl Gustav M45 9mm SMG, near (G_31P), same library |
| `marksman-1` to `marksman-3` | Norinco SKS, near (U_14P), same library |
| `reloadPistol` | gunreload1, Gun reload sounds |
